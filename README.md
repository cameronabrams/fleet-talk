# The fleet talk — v2.0

A rendered copy of *Claude Code as a Research Group*: how one research group uses
Claude Code, skills and a fleet of long-lived agent sessions.

- **[Read it here](https://cameronabrams.github.io/fleet-talk/)** — one slide per screen,
  swipe or tap; the counter opens a list of all slides.
- `fleet-talk-abrams.pdf` — the whole deck, 34 slides plus 10 backup slides.

This repository holds the rendered deck only: `index.html`, `slides/NN.png` at 300 dpi,
and the PDF. The LaTeX sources live elsewhere and are not public.

v1.0, delivered in Córdoba on 23 September 2026, is a separate site:
<https://cameronabrams.github.io/carla-2026/>. It is frozen at the talk as given.
